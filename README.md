# Unemployment Analysis in India using Python

An exploratory data analysis project built with Python, Pandas, and Seaborn to analyze regional unemployment trends, particularly focusing on the impacts during the COVID-19 pandemic period up to 2020.

## 🚀 Project Overview
This project examines unemployment rate variations across different states and regions in India. By leveraging data cleaning and visualization techniques, it highlights key economic insights, geographic disparities, and fluctuations in employment statistics over time.

## 🛠️ Tools & Technologies Used
* **Python**
* **Pandas & NumPy** (for data manipulation, cleaning, and aggregation)
* **Matplotlib & Seaborn** (for data visualization and charting)
* **Google Colab** (as the development environment)

## 📊 Key Insights & Visualizations
* Analyzed regional differences in average estimated unemployment rates.
* Identified states experiencing the highest spikes in unemployment using comparative bar plots and distribution charts.
* Processed timeline data tracking frequency and labor participation rates.

## 📂 Dataset Features
The main dataset (`Unemployment_Rate_upto_11_2020.csv`) includes the following parameters:
* `Region`: State or territory in India
* `Date`: Date of recording
* `Frequency`: Frequency of data collection (Monthly)
* `Estimated Unemployment Rate (%)`: Percentage of unemployed individuals in the labor force
* `Estimated Employed`: Total number of estimated employed individuals
* `Estimated Labour Participation Rate (%)`: Percentage of the working-age population that is economically active
* `longitude` & `latitude`: Geographical coordinates for regional mapping

## 💻 How to Run
1. Clone this repository or download the files.
2. Open the `Unemployment_Analysis.ipynb` notebook in Google Colab or Jupyter Notebook.
3. Upload your unemployment dataset CSV file when prompted.
4. Run the cells sequentially to generate the charts and analysis.
